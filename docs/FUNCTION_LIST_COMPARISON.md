# Simplenote function list comparison: iOS vs HarmonyOS

- **Source:** Simplenote for iOS 4.55, 181 functions.
- **Target:** Simplenote for HarmonyOS, this repository.
- The iOS function list was extracted from the iOS app's source code, and each function was driven
  on the iOS app in an iPhone 16 simulator (iOS 18.3).
- Each iOS function was then looked for in this port: on the HarmonyOS emulator with a screenshot,
  and in the port's source code where a screenshot could not settle it.
- ✅ = the app has the function, ❌ = it does not.
- Level 1 Module is the screen, panel or system surface the function belongs to, and Secondary
  Module is the function itself. The iOS list names one function per row rather than one row per
  tap, so the Three-level module and Level 4 Module columns stay empty.
- As in the Function List workbook, a module is one merged cell over all the rows of its group. A
  markdown table cannot merge cells, so the table below is written in HTML.
- The functional description comes from the iOS list. The port has no function list of its own, so
  there are no HarmonyOS-only rows (– in the summary).
- 181 rows: 171 in both, 10 iOS only.
- The same tables are in the workbook [FUNCTION_LIST_COMPARISON.xlsx](FUNCTION_LIST_COMPARISON.xlsx),
  with each module as a merged cell.
